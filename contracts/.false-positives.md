## Active False Positives

### [FP-001] Unmaintained/unsound dependency advisories ignored in CI

### Detection Details
- **Tool**: Cargo Audit, cargo-deny
- **Rule**: `RUSTSEC-2026-0097`, `RUSTSEC-2024-0388`, `RUSTSEC-2024-0436`
- **Severity**: Informational (all three)
- **Location**: `.github/workflows/rust-security.yml` (`cargo audit --ignore ...`), `deny.toml` (`[advisories].ignore`)
- **Date Detected**: 2026-08-25

### Root Cause Analysis
- **RUSTSEC-2026-0097** (`rand`): unsoundness only triggers when the `log` and `thread_rng` features are both enabled with a custom logger installed and trace/warn logging active during a `ThreadRng` reseed. This project does not enable a custom logger against `rand`'s `thread_rng`.
- **RUSTSEC-2024-0388** (`derivative`): the crate is unmaintained (informational advisory, not an active vulnerability). It is a transitive dependency; no exploit path exists.
- **RUSTSEC-2024-0436** (`paste`): the crate is unmaintained (informational advisory, not an active vulnerability). It is a transitive dependency; no exploit path exists.

**However**, these are **false positives / accepted risks** because:
1. None have an assigned CVSS/critical-high severity — all are advisory-database informational notices (unsound-conditional or unmaintained).
2. The unsound condition in `RUSTSEC-2026-0097` requires a code pattern (custom logger on `thread_rng`) that does not exist anywhere in this codebase.
3. `derivative` and `paste` are transitive build-time dependencies with no known active exploit; upstream has no patched replacement release yet.

### Mitigation Evidence
- **Verification**: `cargo tree -i derivative`, `cargo tree -i paste`, `cargo tree -i rand` to confirm dependency paths remain transitive-only before renewing this exclusion.
- **Re-review**: Re-check `cargo audit`/`cargo deny check advisories` output each quarter; drop an ignore entry as soon as a patched version is available.

### Decision
✅ **Status**: ACCEPTED (False Positive / Accepted Risk)

**Reasoning**: All three advisories are informational, not exploitable in this codebase's usage, and have no patched version to upgrade to yet.

**Approved By**: @solaawojobi00-bit (2026-08-25)

### Follow-up Actions
- [x] Ignored in `cargo audit --ignore` (`.github/workflows/rust-security.yml`)
- [x] Ignored in `deny.toml` (`[advisories].ignore`)
- [ ] Re-verify each quarter per Review Frequency above; remove the ignore once a patched version ships
